# Telegram Client Backend

The backend for a hobby Telegram client built for an **iPhone 5 / iOS 10**. It provides the communication layer between the Cordova frontend and Telegram.

The backend is built with **C# and ASP.NET Core**, using **WebSockets** for real-time communication and **REST APIs** for other operations.

## Project Structure

This repository contains the **backend/server-side** application.

The frontend is maintained separately in the companion Cordova repository .
checkout the frontend in : https://github.com/KaarenMesbah/rocket-client

## About

This is a personal hobby project created to experiment with **C#, ASP.NET Core, WebSockets, REST APIs, and Telegram's API**, with the original goal of bringing a Telegram client experience to older hardware such as the **iPhone 5 running iOS 10**.
