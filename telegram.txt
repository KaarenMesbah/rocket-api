npm install -g cordova@7.1.0

There are tweaks like:

    Insomnia

    Backgrounder

    KeepAlive

    NoSuspend

These tweaks prevent apps from being suspended.

If you install one of these, then:
✔️ Your Cordova app can keep running in the background
✔️ It can poll your API
✔️ It can trigger local notifications
✔️ Even when the screen is off

This is the only way to get real background behavior on iOS 10 with Cordova.
To build with Xcode 8.3.3 (the last version that supports iOS 10 SDK and 32‑bit builds), you need:

    macOS Sierra (10.12) ✅

    macOS High Sierra (10.13) ✅

Both of these can run Xcode 8.3.3 without issues. Anything newer (Mojave, Catalina, etc.) will not let you install Xcode 8.3.3, and anything older (El Capitan) is too outdated for Cordova.
🟦 Recommended choice

    macOS High Sierra (10.13.6) → Best
